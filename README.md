# Mini Checkout and Browser Test Suite

A clean, beginner-friendly single-page checkout web application built with **React**, **Vite**, and **Playwright**.

The complete application is located in the [`mini-checkout/`](./mini-checkout/) directory as specified in the project requirements.

---

## Quick Start
You can run all commands directly from this root directory or from inside the `mini-checkout/` directory:

### 1. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Run Playwright Automated Tests
```bash
npm test
```

### 3. Run Tests in Headed Mode
```bash
npm run test:headed
```

### 4. View Test Reports
```bash
npm run test:report
```

For complete documentation, test plan, and manual testing records:
